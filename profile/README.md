## 🌟 About Lyra Music

Welcome to the official GitHub Organization profile for **Lyra Music** ([github.com/lyraMusicApp](https://github.com/lyraMusicApp)). We build modern, privacy-focused open-source Android music applications using **Kotlin**, **Jetpack Compose**, and **Material You dynamic design**.

### 🛡️ Safety & Protection Guarantees
- **Zero Tracking**: 100% telemetry-free and tracking-free.
- **Data Protection**: All library metadata, playlists, and cached audio stay strictly on your device.
- **Signed & Verified Releases**: Every APK artifact published is cryptographically signed and published with SHA-256 integrity verification.
- **Coordinated Disclosure**: Active security policy and private vulnerability reporting via [SECURITY.md](https://github.com/lyraMusicApp/lyraMusic/blob/lyra/SECURITY.md).
